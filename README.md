# Reversi

Reversi written entirely in CSS. Minimal HTML, zero JavaScript.

**[Play it here](https://surahotoke.github.io/Reversi)** (tested on Chrome 157)

## Files

| File | Role | Plays the part of |
|---|---|---|
| `index.html` | Loads the three stylesheets | - |
| `index.css` | Creates the squares and the text | HTML |
| `style.css` | Draws the board | CSS |
| `script.css` | Makes it playable | JavaScript |
| `single.html` | The same game in one file | - |

## Notes

- It works even with JavaScript turned off in the browser settings.
- There is no pass. If the player to move has no legal move, the game stops there.
